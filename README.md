# Complex Matrix Project

## Описание проекта

Данная программа предназначена для выполнения математических операций над матрицами, содержащими комплексные числа. Программа написана на языке Java и имеет консольный интерфейс, с помощью которого пользователь может выбрать необходимую операцию и ввести элементы матриц.

Проект разработан в рамках первой практической работы.

## Возможности программы

Программа поддерживает следующие операции:

1. **Сложение матриц** — сложение соответствующих элементов двух матриц одинакового размера.
2. **Умножение матриц** — умножение матриц при условии, что количество столбцов первой матрицы равно количеству строк второй.
3. **Деление матриц** — умножение первой матрицы на обратную матрицу второй. Операция возможна, если обратная матрица существует.
4. **Транспонирование матрицы** — замена строк матрицы столбцами.
5. **Вычисление определителя** — вычисление определителя квадратной матрицы.
6. **Консольный интерфейс** — меню для выбора операций и ввода данных.

Программа проверяет допустимость операций и выводит сообщение об ошибке, если операция не может быть выполнена.

## Структура проекта

* `Complex.java` — класс для представления комплексных чисел и выполнения арифметических операций над ними.
* `Matrix.java` — класс для хранения матриц и выполнения операций над ними.
* `Main.java` — главный класс программы, содержащий консольное меню и обработку пользовательского ввода.

## Используемые технологии

* Java
* Java Development Kit (JDK)
* Visual Studio Code

Внешние библиотеки не используются.

## Запуск программы

Для запуска программы необходимо установить JDK и открыть терминал в папке проекта.

### 1. Компиляция

Выполните команду:

```bash
javac Complex.java Matrix.java Main.java
```

### 2. Запуск

После успешной компиляции выполните:

```bash
java Main
```

### 3. Выбор операции

После запуска появится меню:

```text
=== МАТРИЦЫ КОМПЛЕКСНЫХ ЧИСЕЛ ===
1. Сложение
2. Умножение
3. Деление
4. Транспонирование
5. Определитель
0. Выход
Ваш выбор:
```

Введите номер необходимой операции.

## Пример работы программы

Рассмотрим сложение двух матриц:

$$
A =
\begin{pmatrix}
1+2i & 3-i\\
2 & 4+3i
\end{pmatrix},
\qquad
B =
\begin{pmatrix}
1 & 2\\
i & 1
\end{pmatrix}
$$

Результат сложения:

$$
A+B =
\begin{pmatrix}
2+2i & 5-i\\
2+i & 5+3i
\end{pmatrix}
$$

Пример взаимодействия с консолью:

```text
=== МАТРИЦЫ КОМПЛЕКСНЫХ ЧИСЕЛ ===
1. Сложение
2. Умножение
3. Деление
4. Транспонирование
5. Определитель
0. Выход
Ваш выбор: 1

Первая матрица:
Количество строк: 2
Количество столбцов: 2
Элемент [1][1]: 1 2
Элемент [1][2]: 3 -1
Элемент [2][1]: 2 0
Элемент [2][2]: 4 3

Вторая матрица:
Количество строк: 2
Количество столбцов: 2
Элемент [1][1]: 1 0
Элемент [1][2]: 2 0
Элемент [2][1]: 0 1
Элемент [2][2]: 1 0

Результат:
2.00 + 2.00i    5.00 - 1.00i
2.00 + 1.00i    5.00 + 3.00i
```

Ввод каждого элемента выполняется двумя числами: действительной и мнимой частями. Например, для числа `3 - i` нужно ввести `3 -1`.

## Ограничения

* Для сложения матрицы должны иметь одинаковые размеры.
* Для умножения число столбцов первой матрицы должно совпадать с числом строк второй.
* Определитель и обратная матрица вычисляются только для квадратных матриц.
* Деление возможно только при существовании обратной матрицы второй матрицы, то есть при ненулевом определителе.
